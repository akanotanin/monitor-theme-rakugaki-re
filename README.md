# rakugaki re

![rakugaki re](preview.png?v=5)

极简探针（Monitor）的第三方主题。整站是一本摊开的手绘笔记本：奶白纸面铺着淡蓝横格线、
左侧一条红色页边线，所有框线都是虚线手绘的，一台机器一张歪头卡片、顶边贴着胶带。
纯静态前端，只读 hub 的公开接口；国旗、图标与字体都自带，离线可用。

## 设计概念

- **纸与横格**：整个页面就是一张稿纸——通铺淡蓝横格线（背景，随滚动到底）、左侧淡红页边线；
  宽屏（≥1400px）时页边线外侧再排一列打孔与内影，像从线圈本上撕下来的一页。
- **黑板**：暗色不是把纸面反相，是同一本本子的另一页——墨绿黑板、粉笔白字，标记笔换成
  粉笔荧光。「随北京时间自动」那档＝19:00–07:00 用黑板（访客可自行覆盖）。
- **手绘线**：框线全用虚线 + 小半径圆角 + 一丁点旋转；不细抠的角落反而对——但**歪得要有控制**：
  线条抖动全部走 `src/lib/sketch.ts` 的确定性伪随机（`rand01(n, seed)`），因为卡片每 2 秒
  刷新一次，真随机会让整张图抖个不停。走势线与延迟图叠了两层：底层是更淡的错位重描，
  像同一笔手描过两遍。
- **标记笔配色**：红 / 蓝绿 / 黄三支主笔，外加图表用的笔蓝与笔紫；胶带黄、青、粉三色半透明
  （40–55%，底下的纸透出来）。

## 顶栏入口

- **小鸡农场入口图标（自动探测，没有设置项）**：本站 `/chicken/` 上装了那座 3D 小鸡农场才出现，
  没装就什么都不显示、不占位（判据是「那条接口回的是不是 JSON」，不是状态码——hub 对未知
  路径会回落到主题首页并回 200）。装了就有，不必配。

## 卡片

一台一张手绘卡片——名字、在线徽章、四格读数条（CPU / 内存 / 硬盘 / 流量，≥85% 换红笔）、
上下行网速、三网延迟（延迟条 + 数字 + 丢包标注 + 迷你走势线）、运行时长与计费。
窄屏单列、桌面两列起排；卡片带一点点歪头与胶带，悬停时整张抬起来、影子换个颜色。
点卡片进这台机器的详情页。

## 关于备注

备注有**两处来源**，都在 hub 后台的节点里填：

1. **「公开备注」**（hub ≥ 1.3.2，单行 ≤100 字）——写给访客看的那条，随公开视图下发，
   匿名访客也拿得到；
2. **「私有备注」**——写给自己的那条，只下发给登录的管理员。

**两边写法一致**：逗号分隔就是多枚（半角 `,` 与全角 `，` 都认，两侧空白削掉、空片段丢掉），
一枚一枚各自成小标签。卡片与详情页摊的是**私有 + 公开合成的一串**——私有在前、带锁 +
深一档描边（只有登录的自己看得到），公开在后；访客那边 hub 不下发私有备注，所以同一个
位置他们看到的只有公开那几枚。备注摊在哪儿由设置里的「备注显示位置」管（见下表）。

## 主题设置

后台「主题」页的「主题设置」，改完对访客立即生效（值存在 hub 的站点配置里，访客端不落副本）：

**站点图标不在这一页**：hub 1.4.0 起由面板的「设置 → 站点图标」管——选好之后浏览器标签页、
书签、手机主屏幕与顶栏那枚手绘方标一起换；主题自带的那份只在没设图标时兜底。

| 分组 | 设置项 | 默认 | 说明 |
|---|---|---|---|
| 列表页顶部 | 列表页顶部 | 两个都显示 | 分组标签行与概览便签各要哪一档：都不显示／只显示分组标签／只显示概览便签／两个都显示（默认）。便签里是节点在线数、最忙节点、今日与累计流量、实时网速（走势线画的是访客打开页面后自己攒的采样）。 |
| 节点信息 | 备注显示位置 | 卡片与详情页都显示 | 备注小标签摊在哪儿：卡片与详情页都显示（默认）／只在卡片上显示／只在整页详情里显示／都不显示。内容在后台节点里填（见「关于备注」）。 |
|  | 显示的延迟线路 | 空（自动） | 卡片「三网延迟」里显示哪几条线路：每行一个 ping 任务名、最多三条，按填写顺序显示；留空则自动取前三条。名字对不上（改过名、任务删了）的那一行跳过。 |
| 外观 | 主题模式 | 随系统设置 | 整站的明暗，四选一：**随系统设置**（默认，跟访客的 `prefers-color-scheme` 走）／**随北京时间自动切换**／**亮色（纸面）**／**暗色（黑板）**。「自动」按北京时间 19:00–07:00 用暗色（固定 UTC+8），页面开着跨过这两个点也会自己换过来。访客点顶栏那枚太阳/月亮就以他的为准，点回与这里相同的一档＝重新跟着这里走。 |

## 细节口径

- 三网延迟块在卡片上最多三条线路：延迟条按线路分别归一，数字带 `ms`，丢包非零时以红笔标注
  「丢包 x%」。**名字与数值两列按内容放宽**——名字列 = 这一块里最宽的那条（上限 80px，超了截断、
  悬停看全名）、数值列 = 最宽的那枚读数（右对齐），三行之间逐列对齐；短名字（`CT`、`联通`）
  不再在「名字 → 数值」中间空出一大块。
- 详情页的信息格次序是：系统 → 架构 → TCP / UDP 连接 → CPU → 内存 / 硬盘 → 今日流量 →
  在线时间，再是计费与到期；资源页签有**六张图卡**，排成两列三排：网络速率 / TCP·UDP 连接 ｜
  进程 / CPU ｜ 内存 / 硬盘（窄屏单列）。连接数是**一格两值**（`17 / 3`，来自 hub 实时上报的
  `tcp / udp`），画成一张双线图（TCP 笔蓝、UDP 笔粉，不填面积——连接数是计数，不是容量）；
  进程数取自同一个历史桶的 `procs` 列，轴顶补到 4 的倍数（四分刻度才是整数）。
- 详情页的每张图各自包在一张卡里，**与列表卡同一套笔触**：2px 虚线 + 歪圆角 + 逐张轮换的歪头
  （±0.4~0.9°）+ **顶边中间一条胶带**（黄 / 青 / 红三色轮换，角度也逐张错开）+ **硬影子按卡位
  取青 / 红 / 黄**（与列表卡 8n 那套顺序取前六张）。整页的延迟图也是同一张卡，样式不掉队。
  名字下面压着一道荧光笔痕，颜色仍是「这台机器在列表里排第几张」决定的识别色 ——
  点进来还认得出是哪台。
- 整页详情的延迟图可以**滚轮收放纵向范围**（锚点钉在光标压着的那个值上、页面不跟着滚）、
  **按住左键拖着线上下平移**、**双击复位**，缩过之后右上角出现一枚「重置」。横向时间窗口不靠
  拖选：用页签上方那排量程。缩窄后越界的数据点夹在绘图区里，不会画到轴外。
- 读数（CPU / 内存 / 硬盘 / 流量）≥85% 一律换红笔——与店面其它主题同一口径。
- 搜索框只长在列表页：收起是一枚图标，点开长成输入框；接 hub 搜索，分组与概览便签跟着
  一起收窄。
- 离线 / 未接入的机器不参与「最忙节点」与流量合计，但在列表里照常显示（红笔徽章）——并**沉在列表最末尾**：在线优先，离线与「从未接入」的都垫底，各分组/搜索页签里同样如此。
- 「随北京时间自动」在夜里与系统相反时，手机浏览器地址栏那圈颜色（`theme-color`）也跟着
  页面实际用的明暗走。

## 安装

首次安装从 Releases 下载 theme.tar.gz 上传至探针后台，后续可在主题卡片上点击从 GitHub 更新。
