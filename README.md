# rakugaki re

![rakugaki re](preview.png?v=6)

极简探针（[Monitor](https://github.com/monitor-probe/monitor)）的第三方主题。整站是一本摊开的手绘笔记本：
奶白纸面铺着淡蓝横格线、左边一道红页边线，所有框线都是虚线手绘的，一台机器一张歪头卡片、顶边贴着胶带。
纯静态前端，只读 hub 的公开接口；国旗、图标与字体都自带，离线可用。

## 预览

列表页是卡片墙：名字、在线徽章、CPU / 内存 / 硬盘 / 流量四格读数条（≥85% 换红笔）、上下行网速、
三网延迟（延迟条 + 数字 + 丢包标注 + 迷你走势线）、运行时长与计费；卡片带一点点歪头与胶带，
悬停时整张抬起来、影子换个颜色。窄屏单列、桌面两列起排，点开是这一台的整页详情。
离线与「连上但从未上报」的机器照常显示，但沉在列表最末尾（分组页签、搜索页里同样成立）。

详情页：规格局九项（系统 → 架构 → TCP / UDP 连接 → CPU → 内存 / 硬盘 → 今日流量 → 在线时间 → 计费 → 到期），
资源页签六张图卡排成两列三排——网络速率 / TCP·UDP 连接 ｜ 进程 / CPU ｜ 内存 / 硬盘（窄屏单列），
每张卡与列表卡同一副笔触（虚线框 + 歪圆角 + 逐张轮换的歪头 + 顶边一条胶带 + 青 / 红 / 黄硬影子）。
延迟图可以**滚轮**收放纵向范围、**左键上下拖**平移、**双击或「重置」**回自动量程，横向时间量程用页签上方那排。

搜索框只长在列表页：收起是一枚图标，点开长成输入框，接 hub 搜索，分组与概览便签跟着一起收窄。
顶栏那枚小鸡农场图标是自动探测的：本站 `/chicken/` 上装了那座 3D 农场才出现，没装就不占位。

## 主题设置

后台「主题」页的「主题设置」，改完对访客立即生效（值存在 hub 的站点配置里，访客端不留副本）。
站点图标自 hub 1.4.0 起由面板「设置 → 站点图标」管（换主题也保留），主题自带的那份只在没设时兜底。

| 设置项 | 默认 | 说明 |
|---|---|---|
| 列表页顶部 | 两个都显示 | 分组标签行与概览便签：都不显示／只分组标签／只概览便签／两个都显示。便签里是在线数、最忙节点、今日与累计流量、实时网速（走势线画的是访客打开页面后自己攒的采样）。 |
| 备注显示位置 | 卡片与详情页都显示 | 四选一：都显示／只卡片／只详情／都不显示。备注在 hub 后台的节点里填，有公开（访客可见，hub ≥ 1.3.2）与私有（仅登录管理员）两处；半角 `,` 与全角 `，` 分隔、各成小标签，私有那条带锁、排在前。 |
| 显示的延迟线路 | 空（自动） | 卡片「三网延迟」显示哪几条：一行一个 ping 任务名（最多三条），留空按后台顺序取前三条；对不上的名字跳过。 |
| 主题模式 | 随系统设置 | 四选一：随系统／随北京时间自动（19:00–07:00 暗色，固定 UTC+8）／亮色（纸面）／暗色（黑板）。访客点顶栏那枚太阳/月亮可自己覆盖，点回与设置相同的一档＝重新跟着站长走。 |

## 安装与许可

从 [Releases](https://github.com/akanotanin/monitor-theme-rakugaki-re/releases) 下载 `theme.tar.gz` 上传到
探针后台，之后可在主题卡片上点「从 GitHub 更新」。MIT（上游 `monitor-theme-default` 的版权与许可照留，
见 [LICENSE](LICENSE)）；主题包内随附的字体以 SIL Open Font License 1.1 授权，见 [FONTS.md](FONTS.md)。
